# Сторонние компоненты и лицензии

Ниже перечислены основные библиотеки выбранного стека. Фактические версии и транзитивные зависимости определяются окружением сборки. Сценарий Windows-сборки добавляет `DEPENDENCIES.txt` (`pip freeze`) и копирует доступные файлы лицензий установленных пакетов в `licenses/`. Это не заменяет проверку условий лицензий для конкретной готовой сборки.

| Компонент | Назначение | Лицензия / источник |
| --- | --- | --- |
| [Python](https://docs.python.org/3/license.html) | Среда выполнения, упакованная с приложением | PSF License |
| [PySide6-Essentials / Qt for Python](https://doc.qt.io/qtforpython-6/package_details.html) | Оконный интерфейс Qt Core/Gui/Widgets | Community LGPLv3/GPLv3 либо коммерческая лицензия Qt |
| [SimpleITK](https://github.com/SimpleITK/SimpleITK) | Объёмные медицинские изображения и геометрия | Apache 2.0 |
| [VTK](https://vtk.org/about/) | Отображение 3D | BSD |
| [pydicom](https://pydicom.github.io/pydicom/stable/faq/index.html) | Чтение заголовков DICOM и поиск серий | MIT-подобная лицензия |
| [NumPy](https://numpy.org/about/) | Массивы и численные расчёты | модифицированная BSD |
| [PyInstaller](https://pyinstaller.org/en/stable/license.html) | Инструмент Windows-сборки, не библиотека приложения | GPL с исключением для упакованных программ |

Условия LGPLv3, включая требования к распространению бинарных библиотек Qt и возможность их замены пользователем, требуют отдельной проверки перед публичным выпуском. Эта таблица — инвентаризация компонентов, а не заключение о соблюдении лицензий для ещё не собранного Windows-дистрибутива.
