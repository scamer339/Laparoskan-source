# Laparoskan

Настольное приложение для исследовательского и учебного планирования пункции по КТ/МРТ. При запуске открывается **синтетический демо-кейс**; это геометрический фантом, а не снимок пациента. Интерфейс на русском языке. Данные обрабатываются локально.

> **Для исследовательского и учебного использования.** Программа не является сертифицированным медицинским изделием. Сообщения об отсутствии пересечений касаются только структур, размеченных в текущем кейсе.

## Что работает в исходном приложении

- поиск серий DICOM, включая файлы без расширения; проверка шага срезов, ориентации и целостности до загрузки;
- объём и три связанные MPR-плоскости, окно/уровень, прокрутка срезов, масштаб, смещение, физические координаты и линейка;
- редактируемая маска: кисть, ластик, порог по плотности, создание структуры, отмена и повтор;
- ограниченный полуавтоматический рост области от выбранной точки с контролем диапазона HU;
- 3D-поверхности из масок с вращением, масштабом, переключением структур и прозрачностью;
- выбор точки входа и цели, виртуальная игла, глубина в миллиметрах, попадание в размеченную цель, проверка пересечений и консервативная оценка просвета;
- экспериментальный расчёт нескольких вариантов входа по размеченной поверхности тела с объяснением порядка вариантов;
- учебный и экзаменационный режимы с результатами без непрозрачного балла; экспорт CSV/JSON;
- сохранение и открытие переносимого локального кейса `.lapcase`.

Математические соглашения описаны в [ARCHITECTURE.md](ARCHITECTURE.md).

## Запуск из исходников

Требуется Python 3.11 или 3.12, 64-разрядная ОС и видеодрайвер с OpenGL для 3D.

```sh
python -m venv .venv
source .venv/bin/activate
python -m pip install -e . pytest
python -m laparoskan --smoke-test
python -m laparoskan
```

На Windows вместо `source .venv/bin/activate` выполните `.venv\Scripts\Activate.ps1`. После установки доступна команда `laparoskan`. Для переносимого Windows-дистрибутива см. [BUILD_WINDOWS.md](BUILD_WINDOWS.md).

## Быстрый проход демо

1. Откройте «Исследование»: щелчок меняет перекрестие во всех трёх плоскостях. Колесо прокручивает срезы, Ctrl+колесо масштабирует, средняя кнопка сдвигает изображение.
2. В «3D-модель» поверните синтетические структуры и настройте видимость. Они построены из маски; внешний вид не участвует в расчётах.
3. В «Планирование» нажмите «Выбрать точку входа» и «Выбрать цель», затем щёлкните по модели или срезам. Программа построит иглу и рассчитает параметры по исходной геометрии в мм.
4. В «Тренажёр» выберите «Обучение» или «Экзамен», начните упражнение, задайте точки и завершите его. Эталонные точки синтетического случая скрыты в экзамене до результата.
5. В «Результаты» экспортируйте CSV/JSON. Через «Кейсы» сохраните `.lapcase` и откройте его вновь.

Чтобы открыть свои снимки, в «Исследование» выберите папку DICOM. Поиск и загрузка идут в фоне. Если серия имеет несогласованную геометрию, приложение показывает причину отказа, не подменяя повреждённые срезы.

## Границы использования

Сегментацию реальных снимков выполняет и проверяет пользователь. Автоматическая диагностика, подтверждённая клиническая безопасность, действующая УЗИ Fusion-навигация и аппаратное отслеживание не заявляются. При отсутствии разметки сосудов/органов расстояние до них неизвестно. Исходные DICOM не изменяются; сохраняемый кейс может содержать копию объёма, поэтому обращайтесь с ним как с медицинскими данными и не публикуйте без обезличивания.

Клинические DICOM и фотографии не включены в этот репозиторий.

## Дальнейшие направления

Отдельные будущие модули: совмещение с УЗИ (Fusion), подключение УЗ-источника, электромагнитное отслеживание инструментов (EM tracking) и мобильный пространственный интерфейс. Их нет в текущем рабочем процессе; для медицинского применения потребуются самостоятельная проверка точности и соответствующие процедуры допуска.
