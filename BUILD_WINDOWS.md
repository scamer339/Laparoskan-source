# Сборка для Windows

Целевая платформа: 64-разрядная Windows 10/11 с Python 3.11 для сборки. Конечному пользователю Python не требуется: результат скрипта — переносимая папка с `Laparoskan.exe` и ZIP-архив этой папки.

## Локальная сборка на Windows

В PowerShell из корня проекта:

```powershell
./packaging/build_windows.ps1
```

Скрипт создаёт отдельное окружение `.venv-windows-build`, устанавливает пакет и PyInstaller, запускает тесты, собирает приложение в `dist/Laparoskan/Laparoskan.exe` и создаёт `dist/Laparoskan-Windows-portable.zip`. При неуспешных тестах сборка прерывается. Флаг `-SkipTests` предназначен только для отладки сборки, не для выпуска.

После сборки проверьте исполняемый файл:

```powershell
./dist/Laparoskan/Laparoskan.exe --smoke-test
./dist/Laparoskan/Laparoskan.exe
```

Проверка `--smoke-test` подтверждает работу встроенного демонстрационного сценария и зависимостей. Затем вручную проверьте запуск оконного интерфейса, загрузку серии DICOM, сохранение и повторное открытие кейса на целевой машине.

## CI

Файл `.github/workflows/windows-build.yml` содержит ручной запуск сборки на `windows-2022` и публикует ZIP как артефакт GitHub Actions. Workflow работает только после размещения исходного проекта в репозитории GitHub; клинические DICOM туда загружать нельзя.

## Состояние проверки

Текущая рабочая машина — macOS без Windows, Wine или виртуальной машины Windows. PyInstaller создаёт исполняемый файл для той ОС, на которой он запущен. Поэтому наличие скрипта и CI-рецепта само по себе **не означает**, что Windows `.exe` уже собран или запущен; фактическое состояние сборки нужно проверять по результату Windows CI и его артефакту.
